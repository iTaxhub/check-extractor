# Kyriq logo system

The website uses the supplied vector artwork directly. Do not redraw the logo
with image generation: SVG keeps the mark exact and sharp at every size.

| File | Use |
| --- | --- |
| `kyriq-logo.svg` | Primary full-colour lockup on light surfaces |
| `kyriq-logo-white.svg` | White lockup on neutral dark surfaces |
| `kyriq-logo-on-brand.svg` | Lockup on Kyriq indigo surfaces |
| `kyriq-icon.svg` | Primary bare symbol on light surfaces |
| `kyriq-icon-white.svg` | White bare symbol on neutral dark surfaces |
| `kyriq-icon-on-brand.svg` | Bare symbol on Kyriq indigo surfaces |
| `kyriq-app-icon.svg` | App tile, favicon and compact product identity |

Official integration marks live in `public/integrations/` and must not be
AI-redrawn or recoloured.
